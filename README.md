# Collins Market post review

This static noindex preview lets Rich review 24 November and December 2026 drafts. It does not publish posts or send responses to a server. Submitting prepares a summary for Cory and opens an email draft in the reviewer's mail app when available. The reviewer sends the email from that app.

Serve this folder as the site root on GitHub Pages or run `python3 -m http.server 8000` here and open `http://localhost:8000`. Anyone with the deployed link can open the preview.
